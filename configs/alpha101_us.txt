# Alpha101 -- Kakushadze (2015), "101 Formulaic Alphas", arXiv:1601.00991
#
# Transcribed into this repo's expression DSL. Purpose: a published-alpha
# baseline for the LLM candidate sets, and the reference set for the
# memorization test (how close is an LLM "discovery" to a known alpha?).
#
# Operator mapping
#   rank(x)              -> CS_RANK(x)
#   delta / delay        -> TS_DELTA / DELAY
#   correlation / covariance -> TS_CORR / TS_COV
#   stddev / sum / product   -> TS_STD / TS_SUM / TS_PRODUCT
#   ts_min/max/rank/argmax/argmin -> TS_MIN / TS_MAX / TS_RANK / TS_ARGMAX / TS_ARGMIN
#   decay_linear(x, d)   -> TS_DECAY_LINEAR(x, d)
#   returns              -> $return
#   adv{d}               -> TS_MEAN($dollar_volume, d)   (paper: average daily DOLLAR volume)
#                           EXCEPT in alphas 7, 17, 21, 39 and 43, where adv{d} is compared
#                           to or divided by `volume` directly. Dollar volume against share
#                           volume is dimensionally incoherent and makes those alphas
#                           near-constant (alpha007 evaluates to -1 on 99% of observations),
#                           so those five use TS_MEAN($volume, d). Flagged because it is an
#                           interpretation, not a transcription.
#   signedpower(x, e)    -> SIGN(x) * POWER(ABS(x), e)
#   (cond) ? a : b       -> IF_ELSE(cond, a, b)
#   (a < b) * -1         -> IF_ELSE(a < b, 1, 0) * -1     (the evaluator has no bool->numeric cast)
#   (x < c) || (x == c)  -> x <= c                        (the evaluator has no || or ==)
#   scale(x)             -> x, ONLY where the surrounding expression is rank-invariant.
#                           scale() divides by a per-date positive constant, which cannot
#                           change that date's cross-sectional ordering. Used at the outer
#                           level (#28) or under SIGN (#31). Where scale() is composed into
#                           a sum or clipped against a constant it is NOT rank-invariant and
#                           the alpha is dropped instead (#29, #60).
#
# Deviations, all deliberate and listed so they can be checked:
#   - Divisions are epsilon-guarded (+ 1e-8) as everywhere else in this repo.
#     The paper does not guard them; unguarded they produce inf and the rank of
#     an inf is decided by a rounding artefact.
#   - TS_ARGMAX here returns DAYS SINCE the window maximum; the paper's ts_argmax
#     returns the index OF the maximum. The two differ by (window - 1 - x), a
#     monotone decreasing map, so |IC| is unchanged and the sign flips. The
#     scoring pipeline orients signs itself, so this is immaterial to the result.
#   - Alphas above #60 carry non-integer window parameters in the paper
#     (e.g. 8.91644). The evaluator requires positive integer literals, so these
#     are rounded to nearest. Marked "rounded" below.
#
# 51 of 101 are dropped. Every drop is recorded, with its reason, in place.
# Verified against the paper text: no transcribed alpha needs a field the panel
# lacks, every drop-for-field claim matches the published formula, and all numeric
# constants in the 50 transcriptions match the paper exactly.
